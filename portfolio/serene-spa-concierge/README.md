# 🌿 Serene Spa — AI Concierge (Demo)

A calm, working AI chatbot demo for a spa business. Built as a portfolio piece for our Fiverr AI-chatbot service.

**What it does**
- Answers questions about services, prices, hours, location, gift cards, cancellations
- Runs a full **appointment booking flow** and "captures the lead" (reception notification)
- Quick-reply chips, typing indicator, light/dark mode, fully responsive

**Design**
Follows our house Design Law: calm, aesthetic, effortless. Sage/teal + warm cream palette. No bloat — one self-contained `index.html`, zero dependencies.

**Tech / extensibility**
Pure HTML/CSS/JS. The `respond()` logic is structured so a real **OpenAI GPT / Claude** call drops in for full natural-language understanding + document (RAG) training.

**Run it**
Open `index.html` in any browser. Try: *"What are your prices?"*, *"Book an appointment"*, *"Are you open Sunday?"*
