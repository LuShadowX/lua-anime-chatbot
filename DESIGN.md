# 🎨 Design Law — read before building ANYTHING (both branches)

_Our whole brand is "calm, capable, easy." Every project — Branch A (Claude) and Branch B (Gemini) — obeys these._

## The 7 principles
1. **Calm over loud.** Generous whitespace. One clear focal point per screen. Nothing screams for attention.
2. **Vibrant but tasteful.** A *limited* palette: one soft hero color + one warm accent + calm neutrals. No neon overload, no harsh rainbow gradients. Color should feel like a nice room, not a nightclub.
3. **Effortless to use.** The primary action is obvious. Fewest possible choices. Zero learning curve. If a user has to think, we failed.
4. **Pretty & cool.** Soft rounded corners, gentle shadows, smooth micro-interactions, great typography, comfortable spacing.
5. **Accessible & responsive.** High-contrast text, works in light AND dark mode, looks great on mobile.
6. **Original, not a clone.** Solve the real need simply. Do NOT copy the crowded shiny templates everyone already ships.
7. **Fast & self-contained.** No bloat, no heavy dependencies. Loads instantly.

## Palette (starting point — calming & warm)
- **Hero:** soft sage/teal `#5E8B7E` / `#7FB3A3`
- **Accent (warm):** muted coral/amber `#E8A87C` / `#F2C14E`
- **Neutrals:** warm cream `#FBF7F0`, soft slate text `#2E3A38`
- Dark mode: deep slate `#1C2624` bg, cream text.

## The vibe test (ask before shipping)
> "Does this feel calm, look pretty, and work without a manual?"
If yes → ship. If it feels busy, trendy-shiny, or confusing → simplify.
